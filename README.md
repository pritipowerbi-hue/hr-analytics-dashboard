# hr-analytics-dashboard
HR Analytics Power BI dashboard analysing employee attrition, department, gender, education, salary and job role trends from a cleaned HR dataset
An interactive Power BI dashboard that analyses employee data of 500+ employees.
It covers workforce distribution by department, gender, education, city and job role,
salary trends, hiring trends by year, and employee attrition.

The raw dataset was messy (inconsistent department and gender names, mixed salary
and date formats, duplicate IDs, missing values), so it was cleaned and standardised
in Power Query before building the report.

![HR Dashboard](Screenshot%202026-10-22%20144147.png)

## Files
- `New HR dashboard with styling.pbix`: Power BI report
- `HR_Employee_Dataset_MESSY.xlsx`: raw dataset

## Tools
Power BI, Power Query, DAX, Excel

## How to open
Download the .pbix file and open it in Power BI Desktop.
